# 397条规则的结构与来源审计

本轮已逐行阅读全部397条 `scope`，保留原始 `description`、版本、税号、别名与文件指纹；产出397行 **AI source-coded silver** 字段。审查范围是条款表面结构和需要绑定的对象、计量属性、分支与外部定义线索，不是397条已被专家确认的可执行法律本体。原冻结规则文件未修改。

**编号约定**：本报告的索引或“行”均指 JSON 的零基 `index` 字段（0–396），不是PDF行号或读者的一基序号。例如 index 13 为第14个库存记录，index 95 为第96个；法律来源定位同时保留正式规则标识。

## 实际执行与编码层次

1. **全量可复算层**：397行保留原文及字符跨度。1131个标点分段仅供检索；逻辑词、对象词与外部引用候选均以实际子串验证。没有把这些数量称为必要条件数或复杂度。
2. **全量逐行语义阅读层**：397行分别指定目标层次、逻辑特征、明示计量属性、外部标识符类型；89条有针对性的对象／解释说明。书面编码表在 `encode_semantic_reading.py` 中，每行都有显式索引和人工式AI阅读编码，不是由正则猜语义后自动称已审。`actual_reviewed=true` 仅表示这些字段本轮已读已编码；不表示法律专家确认。
3. **全量逐字条件组层**：354条产品描述均已逐条重新读取并选择语义分组边界，形成1,096个带原文起止位置的粗粒度必要条件组，全部通过字面一致性检查。最初30条保留其明确的摘录组，其余324条在 `expand_condition_groups.py` 中逐行显式指定边界锚点，没有用标点或连接词计数自动生成分组。类别备选、成套部件、同一对象的尺寸向量或带条件的标准要求可在一个组内，因此**组数不是原子条件数**，不作跨规则复杂度排名。43条code-only记录的额外产品条件组为0，其税号或日期换码门槛另列；这不代表法律条件总数为0。
4. **保留不确定层**：397条现均有 `coarse_required_group_count`；原子层的 `necessary_condition_count`、外部定义是否已解决、形式化量词仍为null。不能将原子层null当0。13条具有显式 unresolved 结构／含义／来源异常标志；其粗组保留整个有争议短语，并不解决该争议。这不是全部实际法律歧义的穷尽计数。其余也仅标 source-surface structure，未认定解释已唯一解决。

## 需要保留的来源异常

索引第12页的 `20(ttt)(iii)(179)`（行211）把已装配货架宽度上界记为 **183 m**，不是183 cm。本轮从现有官方PDF的转录页中核对到相同字面。它可能是源文排印问题，但本审计不擅自订正，也不将其作为合理物理上界用于行为金标；需要其他正式通知或勘误来解决。`20(ttt)(iii)(128)`（行155）的5000 BTUs没有明确每小时时间基准，不能自动转成功率。行297的9.5mm轴未明确维度名；行342的“Protective Articles”也不足以自行补出产品定义。

## 复算与停止边界

按顺序运行 `encode_semantic_reading.py`、`annotate_condition_groups.py`、`expand_condition_groups.py`、`build_inventory_audit.py`，再运行 `validate_inventory_audit.py`。它们只读取冻结输入并写本目录结果，不训练模型、修改标签或更改旧主文。程序校验验证的是来源一致、映射和计数；不把代码通过当语义独立有效性证明。

可用于主文的贡献表述是：资源同时公开**规则库存的覆盖边界与无法机械处理的绑定要求**，防止用窄数值测试的得分代表完整法律适用能力。本轮完成了全量结构银标签和覆盖映射，仍不宣称全量原子化、全部外部定义已解析或专业法律金标。
